# MotoResQ — Phase 1 Frontend Prototype

A static HTML/CSS/JavaScript prototype for the MotoResQ Smart Accident Detection & Emergency Alert System.

## Run locally
Open `index.html` in a browser.

## Features
- Landing page
- Interactive dashboard
- Rider profile saved with LocalStorage
- Emergency contact management
- Demo location
- Accident simulation
- 30-second cancel countdown
- Alert history

## Deploy
Upload these files to a GitHub repository and enable GitHub Pages from the repository's Pages settings. The `index.html` file is the site entry point.

No real GPS, SMS, phone calls, ESP32, or backend are included in Phase 1.
